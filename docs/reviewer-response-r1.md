## 一、主要意见

### 1. 理论部分需要正式化 — **✅ 已改**

§3.2 重写为「Setting / Assumption / Theorem / Proof / 三条推论 + 四条限定」的结构：

- **明确定义 `Y`（future）**：打分已知续写时 `Y` 就是该续写；度量生成文本时 `Y` 是模型随后产生的完成。
- **给出联合分布与条件独立结构**：`c_t = F(h_t, e_{t-r:t})`，条件在 `h_t` 上构成 Markov 链 `Y -> (h_t, e_{t-r:t}) -> c_t`。
- **给出链式不等式**：`I(Y; c_t | h_t) <= I(Y; e_{t-r:t} | h_t) <= I(Y; w_t | h_t)`，并说明第二步依据是「卷积只读取键落在同一 `kn` 个 token 内的行」。
- **随机性**：新增 Assumption（deterministic read-out）。推理时家族内唯一随机性是 `Y` 自身的采样，属于被预测量而非通道的一部分；若读出随机（dropout / 带噪寻址），界以 `I(Y; c_t | h_t, xi) <= I(Y; w_t | h_t, xi)` 形式成立，且对 `xi` 边缘化不会增大左侧。
- **`a_t = A(w_t, h_t)`**：新增 Qualification 2 —— 由于界条件在 `h_t` 上，这种做法**不逃逸**界。**我们同时承认并更正了初稿的一处错误论断**（初稿写「只有 query-dependent 寻址能放松界」，这是错的）。
- **递归/反馈回路**：新增 Qualification 3 —— 界是**逐位置**的且条件在 `h_t` 上，而 `h_t` 本身是此前全部注入的函数，所以界约束的是「给定已产生的状态，记忆在这一位置新增了什么」，**不构成对整条序列的界**。位置的 chain rule 需要处理「`h_t` 不是过去的充分统计量」，因此 `t'<t` 的行会留存于 `h_t` 并影响任意远的后续 token。我们明确写下：逐位置的界禁止单点引入超出窗口的信息，**不禁止跨位置累积**；而本文测到的效应正是这种累积。
- **紧性**：新增 Qualification 4 —— 界在 `I(Y; w_t | h_t)` 大时是空洞的，而我们的任务上它不为零（显式 count trigram 0.2535 vs 下限 0.0537），因此**零内容结果本身不构成对界的证据**，分离工作见 §4.7，且我们承认没有完全做到。

此外，我们把窗口算术化简为一个此前没有写出的闭式：`|w_t| = kn`（卷积核 × 键阶），4×3=12。

### 2. 窗口算术需要代码级证据和消融 — **✅ 已补可执行证据**（本轮最重要的新增）

新增 `tests/test_window_receptive_field.py`，**用执行而非读配置**来测有效感受野：构建真实的 `Qwen4ExpTextPLELayer`，固定 query 隐状态，改动单个输入 token，观察输出位置是否变化。**断言的是支撑集而非幅度**，因此对 dtype、种子与量级不敏感。

覆盖 8 组几何，验证 `window = kernel × ngram`：`(4,3)=12`、`(1,4)=4`、`(2,3)=6`、`(4,2)=8`、`(4,4)=16`、`(3,3)=9`、`(1,3)=3`、`(2,2)=4`。对每一组：窗口内所有 lag 都使输出变化，窗口外所有 lag **变化恰好为 0**。

- **消融**：kernel=1 即「移除卷积」，得到 `window = ngram`，这正是 V4.1-Flash 的 4。
- **「卷积是否在执行的路径上」**：本测试执行的就是真实层类，所以它检验的是执行路径本身，而不是我们对配置的解读。
- 另加一条：窗口是**架构属性**，不随 embedding 表大小变化 —— 这条正是「用玩具规模配置测生产几何」这一论证的许可证。
- **V4.1-Flash 的表述已弱化**：我们按其公开描述把它建模为「移除卷积」这一消融，**没有运行其发布权重**，论文里已明确写成「关于它所描述的设计，而不是关于我们测过的实现」。

### 4. 分离「界」与「read-out 缺陷」 — **部分已改 ✅ / 核心实验 🧪**

已改：

## 三、我们主动更正的、审稿人未提到的

1. **初稿有一条错误论断**：「只有 query-dependent 寻址能放松界」。事实上用 `h_t` 做 query 的寻址在条件界下**不逃逸**。已在 §3.2 Qualification 2 更正。
2. **§3.2 第三条推论过度声称**：「增益应集中在稀有 n-gram …… 我们的测量一致」。稀有度**从未被检验**，且 round 164 已证明在窗口尺度上**不可被语料计数估计**（k=3 时 93% 计数为 0）。已改写为开放问题并说明原因。
3. **一个新增的、审稿人第 1 条「紧性」所指向的澄清**：界约束的是**信息**，不是**效应大小**。一个常向量 `c_t` 满足 `I(Y; c_t | h_t) = 0`，却仍能移动残差流从而改变输出分布。因此**大而可复现的行为效应不构成对界的反证**，界也不构成「注入无害」的论据。这恰好是本文测到的情形，现在写成 Qualification 1。
