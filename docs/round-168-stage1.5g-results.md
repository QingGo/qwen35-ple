## 2. 三条读数

### 2.1 损失定位在阶④ —— 这是本级的**主要**结论

① 天花板(三元组)② 寻址(无损)③ 行内容(R=0.50–0.74)**都是有内容的**,
  而 ④ 读出(1.5c 替换 THIN/EMPTY、1.5e 互补 8/8 ABSENT)归零。

⇒ 论文的结论从"PLE 没用"变成**"信息在表里、寻址完美、然后被读出毁掉"**。

### 2.2 MLP 处处优于线性 ⇒ 线性 R 是**下界**,且松紧因域而异

| 域 | MLP / linear |
|---|---|
| stem | **0.999 – 1.018**(非线性读出帮不上) |
| wiki | 1.075 – 1.106 |
| code | 1.094 – 1.156 |

这是 TD-9 那条警告的量化版:**stem 的行已被线性读出榨干,wiki/code 还有 8–16% 的可回收结构。**
所以"损失全在读出"要分域说:**code 的行其实相当好,损失更多在读出;stem 正相反**
(详见 `docs/round-169-rk-curve-exploratory.md`)。

### 2.3 ⚠️ 两个 K 值都贴着地板,必须原样报出

**wiki-K5000 的 0.5091 与 stem-K5000 的 0.5015 距 0.50 地板只有 0.0091 / 0.0015。**

判定按冻结规则**成立**,但"贴着地板通过"和"稳稳通过"不是一回事。
探索性的 R(K) 曲线进一步显示:**wiki 在 K=20000 时 R=0.4858,会翻成 `ROWS_DEGRADED`**
——即**这个标签依赖候选集**。见 `docs/round-169-rk-curve-exploratory.md` §1.1。

## 3. 口径:位置集是被**重建**的,不是新采样的

本级的关键工程点是:①②④ 已对齐到 1.5c 的同一批位置,③ 之前挂在 round-161 的 ~59% 上
(不同的位置采样、不同的候选集、不同的切分)。为了对齐,位置集**从 1.5c 自己的两个产物重建**:

```text
valid  = isfinite(cnt_nll) & isfinite(bb_final) & isfinite(bb_lens)
mask   = zeros(n, bool);  mask[positions] = True
valid &= mask
aligned = flatnonzero(valid)
```

**并强制与 1.5c 记录的 `n_scored_positions` 逐一对拍,不一致就拒绝写盘**(`ALIGNMENT DRIFT`)。

| 域 | 重建 | 1.5c 记录 | 一致 |
|---|---|---|---|
| wiki | 1,152,327 | 1,152,327 | ✅ |
| code | 515,068 | 515,068 | ✅ |
| stem | 44,554 | 44,554 | ✅ |

另有一个细节:每个域**恰有 1 个位置**在最末尾(`t+1 == T`),没有下一 token 可作标签,
因此写盘的是 1,152,326 / 515,067 / 44,553。

**仪器是复用而非新造**:`scripts/probe_table_next_token.py` **只新增**
`--eval-tokens` / `--aligned-positions` / `--aligned-train-frac` / `--aligned-temp-frac`
四个参数,默认路径逐字未改。切分是**连续 60/40**(前 60% 训探针,后 40% 评),
温度集取自训练块的尾部——**这不会影响判定,因为判定量是 top-1,而 top-1 是 argmax,与温度无关**。

## 4. 承限

1. **K 冻结为 5000(主)+ 1000(敏感)**,§4.1 的保守条款只在这两者之间裁决;
   探索性曲线显示该判定不 K-鲁棒(§2.3)。
2. **两个探针都是下界**(TD-9):线性的 R 与 MLP 的 R 都是下界,都不构成"行里没有"的证明。
3. **行表是 fp8**,量化误差是表的一部分,不修正。
4. 探针输入是 16 行拼接(2560 维),与生产 reader 所见一致;结论**不**适用于"只用某几个头"的变体。
5. 本级**不能**反推"记忆有用":R 高只说明**行里有东西**;
   "有没有用"由 1.5c(替换上界)与 1.5e(互补性)裁决,而两者都是否定的。
6. 全部为 **0.8B + 冻结行 + 冻结 reader**;不外推到其它规模或共训配置。
