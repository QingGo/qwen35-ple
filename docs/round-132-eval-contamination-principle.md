# Round 132：评测记忆/世界知识时，训练语料应该包含评测集知识吗？

> 日期：2026-09-08
> 问题：如果我们测的是“记忆能力 / 世界知识”，训练语料是否应该带上评测集里的知识？
> 答案：**要看测的是“记忆检索能力”还是“参数化记忆/过拟合”。**

---

## 1. 两个不同的目标

### 目标 A：测“模型能否从外部 PLE 记忆里读取知识”

这是我们希望验证的核心问题之一：

```text
给模型一个外部知识记忆表，
模型能否通过 reader 读取并用它回答问题。
```

在这种设定下：

```text
记忆表/训练语料【可以】包含评测知识。
```

因为外部记忆本来就是知识库。

但必须满足：

```text
reader 训练数据【不能】包含评测用的 question-answer 对。
```

否则就变成：

```text
reader 记住了评测答案，
而不是学会读取任意外部记忆。
```

### 目标 B：测“模型参数里是否学到了世界知识”

这是传统的 knowledge 评测：

```text
不看外部记忆，
只问模型本身知不知道。
```

此时：

```text
训练语料【不应该】包含评测答案。
```

---

## 2. 标准做法：知识库训练/评测 split

正确设计应该是：

```text
知识库 KB：
  train_split：用于构建 PLE 表 / 训练 reader
  eval_split ：用于评测，绝不参与 memory 构建或 reader 训练

问题 QA：
  train_split：用于训练 reader 的使用方式/格式
  eval_split ：用于最终测评
```

关键：

```text
不共享：KB.eval 中的知识
不共享：QA.eval 中的 question-answer 对
```

---

## 3. 可以包含什么，不可以包含什么

| 内容 | 是否允许出现在训练语料/reader 训练中 |
|---|---|
| 通用领域文本（Wiki / FineWeb / 百科） | 允许 |
| 与评测同领域的实体/概念 | 允许 |
| 评测题所用知识点的“来源段落” | 允许（如果作为 memory value） |
| 评测题本身 | 不允许 |
| 评测标准答案 | 不允许 |
| 评测题 + 答案的完整 QA 对 | 不允许 |
| 评测题答案的改写/近似答案 | 原则上不允许，需污染审计 |

---

## 4. 我们的情况

我们之前的 1M 实验已经做了污染审计：

```text
M1–M5 语料均不允许包含：
- 答案短语
- 完整问题
- QA 组合
```

这是正确的。

但还需要进一步明确：

```text
1. PLE 表本身用的语料，是否包含评测知识？
   - 如果 PLE 表是“外部记忆知识库”，可以包含知识；
   - 但不能包含 eval QA 对。

2. reader 训练语料：
   - 应该用“任务格式”数据；
   - 不能包含 eval QA 对；
   - 可以包含同领域知识文本。
```

---

## 5. 可复现的评测协议

建议：

```text
1. 构建 KB：
   - 用 train 知识构建 PLE 表 / memory index
   - 严格排除 eval question/answer

2. 训练 reader：
   - 用 train question + 通用文本
   - 不用 eval question/answer

3. 评测：
   - 用 eval question
   - 允许访问 PLE 表（但该知识不能来自 eval 泄漏）

4. 双向污染审计：
   - KB → eval QA
   - eval QA → KB
   - reader train → eval QA
```

---

## 6. 如果你想证明“PLE 是真正的知识记忆”

最强设计是：

```text
A：train knowledge KB → PLE 表 → reader；
B：unseen knowledge KB → PLE 表 → reader；
C：随机/control KB → PLE 表 → reader。
```

如果在 unseen KB 上 real 仍 > control，说明：

```text
reader 学会了“如何读取任意外部记忆”，
而不是“记住了某几条答案”。
```

这才是最有说服力的记忆能力证据。

---

## 7. 一句话

> 测“参数化知识”：训练语料不能包含评测知识。
>
> 测“外部记忆读取能力”：记忆表可以包含知识，
> 但 reader 训练和评测必须使用**不重叠的知识 split**，
> 并且必须做双向污染审计。
>
> 最有力证据是：
> **在训练时从未见过的知识库上，real 仍显著 > control。**
