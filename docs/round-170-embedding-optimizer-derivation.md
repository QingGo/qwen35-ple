# 嵌入层的"最优优化器":从第一性原理推导

**问题**:对于一个 Engram/PLE 层(更广义:任何稀疏嵌入表),是否存在比 Adam 更合适的优化器?
**方法**:先把"更新一行"写成一个**统计估计问题**,解出最优步长,再看它与已发表工作的关系。

---

## 0. 结论先行

```text
逐行步长权重     w_i = c_i^eff / (c_i^eff + k),      k = σ²/γ
                 ├─ c_i^eff = 该行的有效样本数(= 它在训练流里的计数,见 §5)
                 ├─ σ²  = 单个样本的梯度噪声方差
                 └─ γ   = "这一行还有多少系统性东西要学"的方差

完整更新         δ_i = −η · w_i · m̂_i / √(v̂_i + ε)      ← 权重乘【步长】,不能乘梯度
                 v̂_i = (c_i v_i + k_v v_pool)/(c_i + k_v)  ← 第二项修正:合并方差估计
```

**两个关键点**:
1. `w_i` 必须乘**步长**而不是梯度 —— Adam 对梯度整体缩放不变,乘梯度会**完全抵消**。
2. **两个 regime 由 k 决定**:从头训练时 γ 大 ⇒ k 小 ⇒ w≈1(全速训);
   预训练冻结表上微调时 γ 小 ⇒ k 大 ⇒ **w≪1(大部分行不该动)**。

---

## 1. 设定

行表 `E ∈ ℝ^{n×d}`,从冻结先验 `E⁰` 出发微调。行 `i` 在训练流里被寻址 `c_i` 次。
记扰动 `δ_i = e_i − e_i⁰`。

**假设 A1(局部二次)**:留出损失的逐行展开

```text
L_i(δ) = L_i(0) + ḡ_iᵀ δ + ½ δᵀ H_i δ + O(δ³)
```

`ḡ_i = ∇_δ L_i(0)` 是**总体**梯度,`H_i ⪰ 0` 是总体 Hessian。

**假设 A2(随机效应)**:训练流上第 k 次命中给出的梯度

```text
g_{i,k} = μ_i + ε_{i,k},    ε ~ (0, Σ_i) i.i.d.
μ_i ~ (ḡ, Γ_i)              ← 行与行之间的"真实梯度"本身有分布
```

`Γ_i` 是**行间**方差(有多少系统性差异),`Σ_i` 是**样本内**噪声协方差。

---

## 2. 推导

### 2.1 最优步长用后验均值

我们要的是 `μ_i`(这一行真实的梯度方向),而样本均值
`ā_i = (1/c_i) Σ_k g_{i,k}`,`Cov(ā_i | μ_i) = Σ_i/c_i`。

正态随机效应模型下,**后验均值(BLUP / James–Stein / 岭回归)是**

```text
μ̂_i = ḡ + Γ_i (Γ_i + Σ_i/c_i)^{-1} (ā_i − ḡ)          …(★)
```

再代入 A1 最小化 `ḡᵀδ + ½δᵀHδ`,得

```text
δ_i* = − H_i^{-1} μ̂_i
```

**同向各向同性**(`H = hI`,`Σ = σ²I`,`Γ = γI`)时,(★) 退化成

```text
w_i  ≡  γ / (γ + σ²/c_i)  =  c_i / (c_i + k),      k ≡ σ²/γ
```

**∎ 这就是逐行步长权重 `c/(c+k)`,以及常数 k 的来源 —— k 不是超参,它是"噪声/可学信号"之比。**

两个极限:
- `c_i → ∞`:`w_i → 1`(样本足够,照常走)
- `c_i → 0`:`w_i → 0`(**不要动;先验 `e_i⁰` 比一个样本的估计更好**)

### 2.2 权重必须乘步长,不能乘梯度

Adam 的更新是 `η · m̂/√v̂`。若把 `w_i` 乘到梯度上:`g → w g`,则
`m̂ → w m̂`、`v̂ → w² v̂`、`√v̂ → w√v̂`,**商不变**。所以

> **任何"给梯度加权"的实现都是 no-op。必须乘在步长上。**
> (`scripts/round169_train_rows.py` 的 `SparseAdam(row_scale=...)` 正是乘在步长上。)

### 2.3 为什么 Adam 恰好是这里最坏的归一化

行 `i` 只被命中一次时:`m̂ = g`,`v̂ = g²`,于是

```text
m̂/√v̂ = g/|g| = sign(g)      ⇒   更新幅度 = η,【与 |g| 无关】
```

**一个只出现一次的三元组,拿到一次满步长、方向由单个噪声样本符号决定的更新。**
这正是我们实测到的机制(rung B1:稀频带受害、lr=1e-3 下 80% 伤害在第一轮)。

### 2.4 第二项修正:合并的方差估计

同一随机效应模型其实也给出了**二阶矩的最优估计**。行内平方梯度的期望含噪,
用行间总体做先验收缩:

```text
v̂_i = (c_i · v_i + k_v · v_pool) / (c_i + k_v)
```

- `c_i` 大:用行自己的 `v_i` ⇒ 正常 Adam
- `c_i = 1`:`v̂_i ≈ v_pool` ⇒ 步长变成 `η·g/√v_pool ∝ |g|`
  ⇒ **对稀频行恢复"梯度小则步子小"的 SGD 行为**,而不再放大单个噪声符号

> **这一项与 §2.1 的 `w_i` 是不同的东西**:`w_i` 改**幅度**,这一项改**方向**。

## 3. 两个 regime:k 的符号意义

k = σ²/γ,而 γ 是"这一行还有多少**系统性**的东西要学"。

| | `e_i⁰` 是什么 | γ | k | 最优 `w_i` | 谁 |
|---|---|---|---|---|---|
| **从头训练** | 随机初始化 | **大** | 小 | **≈ 1** | Engram / 一切预训练 |
| **预训练冻结表 + 同域微调** | 已经很好的先验 | **小** | **大** | **≪ 1** | **我们** |

**⇒ 文献里"嵌入层学习率应该调到最大"的结论,和我们"大部分行不该动"的结论,
不是矛盾,是同一个公式的两个 regime。**

**已发表的直接证据**:Kalra & Barkeshli([2605.21486](https://ar5iv.labs.arxiv.org/html/2605.21486),
Meta Superintelligence Labs + UMD)做了 16 组消融,结论是

> μP 相对 SP 的**压倒性收益,仅仅来自把嵌入层学习率最大化**。
> 因为在 SP 里嵌入层 LR 是 `Θ(1/n)` 而隐藏层也是 `Θ(1/n)`,
> 但**嵌入是逐 token 查表、LayerNorm 是逐元素操作,都不对 width 求和**,
> 所以它们的 LR 应当是 `Θ(1)`。嵌入层学习率是**训练瓶颈**。

**这正是"从头训练"那一列。** 我们的实验是另一列,而两者由同一个 k 控制。

## 4. 多 epoch 的修正:`c_i` 才是有效样本数

我们的运行是**对同一条流做 4 个 epoch**。行 `i` 拿到 `4·c_i` 步梯度,
但**被访问的还是那 `c_i` 个位置**。设 epoch 间相关系数 ρ(精确复读时 ρ≈1):

```text
c_i^eff = c_i · E / (1 + (E−1)ρ)
```

- `ρ → 1`(精确复读):**`c_i^eff = c_i` —— 4 个 epoch 不比 1 个 epoch 多任何信息。**
- 多出来的步数只累积噪声,不累积信号。

**实测吻合**:1 epoch → Δ = −0.26370;4 epoch → Δ = −0.33127。
**4 倍步数只多 26% 伤害**,与"额外 3 个 epoch 没带来信息"一致。

这与 **"Larger Datasets Can Be Repeated More: A Theoretical Analysis of Multi-Epoch
Scaling in Linear Regression"**([ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/eb3551aeb5390d742733f62d35a98bf6-Abstract-Conference.html))
是同一条定理的总体版本:**数据相对模型越大,越经得起重复**。
逐行地说:**`c_i` 大的行经得起多训,`c_i = 1` 的行一次都不该训。**

## 6. 哪些优化器**不该**用,以及为什么

| 优化器 | 它做什么 | 为什么在这里是错的 |
|---|---|---|
| **Adam / AdamW** | 逐坐标尺度不变 | `w_i ≡ 1`(§2.3)—— 正是病理本身 |
| **Muon** | 对动量矩阵做 Newton–Schulz **正交化** | 行是**独立参数**(编码是单射),无矩阵结构可正交化;正交化会**混合行**,人为制造串扰 |
| **PSGD / 白化系列** | 显式强制**对梯度缩放不变** | 把 §2.3 的病理从坐标级**提升到矩阵级**:更加放大"单样本满步长" |
| **Shampoo** | Kronecker 两侧预条件 | 左因子作用在**行方向** ⇒ 混行;且 m = 667,404 存不下 |
| **纯 SGD** | 步长 ∝ 梯度 | **反而更接近正确**:稀频行梯度小 ⇒ 步子小。只缺 `w_i` 的显式收缩 |

**注意 Muon/PSGD 与 Engram 并不矛盾**:Engram 用 Muon 训练的是 **MoE 骨干的稠密权重矩阵**,
那里 Muon 的前提成立。**冲突只发生在把它用到稀疏嵌入表上。**

## 7. 可直接测的三个预测

推导给出的形式可以逐一证伪:

| # | 预测 | 判据 |
|---|---|---|
| **P1** | 把 `w_i = c/(c+k)` 乘在**步长**上,优于硬掩码 | 同一 lr=1e-4 下,`Δ_soft > Δ_hard(N≈k)` 且低频带损伤更小 |
| **P2** | 乘在**梯度**上是 no-op | `Δ(w·g) ≈ Δ(g)` —— 若不等,推导错了 |
| **P3** | 合并的 `v̂` 改善稀频行 | 只改 `v̂`,稀频带 Δ 上升,高频带不变 |

**特别地 P2 是一个"零成本证伪"**:如果乘梯度也有用,说明 Adam 的尺度不变性在我们的实现里
没有真正生效(例如 `eps` 相对 `v̂` 不可忽略),那本身就是一个必须知道的实现事实。

## 8. 承限

1. 推导用的是**各向同性**假设(`H, Σ, Γ` 都是标量倍数)。真实情形是矩阵,最优权重是
   `Γ(Γ + Σ/c)^{-1}` 而不是标量 —— **标量形式只对"每行一个共享方向"严格成立**。
2. `k` 没有被测量,只是一个解释性常数。**要用它必须估计 k**(例如扫 k 看 Δ(k) 的峰)。
3. 推导把"留出梯度与训练梯度之差 Δ_i"隐含进了 γ。**若 Δ_i ≠ 0(域偏移),`w_i` 的形式不变
   但最优 k 会变** —— 这正是"训练到底有没有用"取决于域偏移大小的原因。
4. 未做实验验证。
