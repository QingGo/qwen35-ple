3. **第二大的债是"提案执行债"**：`round-20` §3、`round-146` §4、`session-log:3030`

4. **下一阶段应该是"两条从未测过的轴"先跑**：effective depth（④）+
   read-out 初始化/秩（②）。两者都便宜、都在官方设计的必动清单里、

## 1. 终极目标（第三版）

### 1.1 原始表述与两次修正

```text
v0（原始）  纯 PLE 嫁接，通过少量训练显著提升 0.8B 通用性能
v1（round-153）  在固定"激活算力+内存预算"下，外部 n-gram 记忆在哪些任务签名上
                 能超过同等预算的纯参数方案？          ← 从"能否"改为"何时"
v2（round-157）  ＋ 该通道**不可能**承载上下文条件化的知识（可证明，非经验）
v3（本文）       ＋ 若价值存在，它在"释放有效深度 / 提供权重压不住的表面先验"轴上 ——
                 而这一轴我们从未测量
```

### 1.2 为什么 v3 是必要修正

Engram 官方（arXiv 2601.07372）明确报告：**记忆在推理上赢的比在知识上多**
（BBH +5.0、ARC-C +3.7、HumanEval +3.0、MATH +2.4 vs MMLU +3.4、CMMLU +4.0），
机制解释是 *"relieves the backbone's early layers from static reconstruction,
**effectively deepening the network**"*。

对照我们的证据：

| 我们的测量 | 落在哪一轴 | 与 Engram 的关系 |
|---|---|---|
| round-162 六臂 TV = 0.0000（跨语料输出分布一致） | **知识轴** | Engram 自己承认收益最小的轴 |
| round-165 答案位置寻址逐字节常量（每任务 1/200 条） | **知识轴**，且被前提强制 | 界的前提，不是新信息 |
| round-162/166 `code>wiki` 三骨干全部存活（等长校正后 +0.0399 / +0.2404 / +0.0239） | **先验/格式轴** | **Engram 说收益所在的那一轴** |
| effective depth | **从未测量** | Engram 机制主张的轴 |

> **结论：我们的负结果不是对 Engram 的反驳，而是它最弱那一轴的独立复现；
> 我们的正结果恰好在它最强那一轴的边缘，却被当作噪声处理。**

### 1.3 v3 目标陈述（三个可判定子目标）

> **在 iso-budget 下判定外部 n-gram 记忆的价值轴。**

| 子目标 | 判定问题 | 已有工具 | 状态 |
|---|---|---|---|
| **(a) 机制轴** | PLE 开/关是否改变骨干的 effective depth？ | logit-lens KL / top-5 overlap / 残差余弦 / 跳层影响 / 残差擦除（Csordás et al.） | **从未测量** |
| **(b) 优势区间** | 匹配"激活算力+内存"时，质量-字节-算力曲线的相变点在哪？ | round-158 计数参照系（32 MB → NLL 5.3368 / top-1 25.25%；天花板 4.94） | 计数侧已有，**参数侧缺** |
| **(c) 产品形态** | 最小可用记忆的端侧四元组（参数量/内存/吞吐/热插拔）？ | round-152 G3（NVMe 462K rows/s，RSS ≈400 MB） | NVMe 通过，USB/SD 未测 |

**停止规则（v3）**：若 (a) 与 (b) 同时为负 —— 即冻结嫁接既不提高有效深度、
也不在 iso-budget 下占优 —— 则方向诚实关闭，交付物是**边界条件论文 + 平台化形态**，
通用性能目标交还参数与数据侧。若 (a) 为正，则方向**不是关闭而是重定位**，
主战场从"知识注入"改为"深度释放 + 表面先验"。

## 3. 本 session 暴露的技术债（新增 8 类）

round-153 的债表是**"实验静默没跑"**这一类（LoRA 未进 optimizer、对照没真关、关机判据不可信）。
本 session 暴露的是**三个全新类别**，其中第一类最危险。

### TD-1 测量效度债（P0 —— 会产生"看起来对"的错结论）

| 项 | 内容 |
|---|---|
| 实例 | `domain_fingerprint` 标记计数 = **不同标记的出现个数**，因此随生成长度单调上升；0.8B 的 prose 方向被抬高 40% |
| 根因 | 指标定义（distinct marker count）与结论变量（语料指纹）之间隔着一个**未建模的滋扰变量**（长度），且该变量在 regime 变化时翻转符号 |
| 为何 round-153 没抓到 | round-153 的债是"实验没跑"；这是"**实验跑了，但量的是别的东西**" |
| 修复 | **每个指标必须有一个滋扰变量扰动测试**：只动长度/格式/seed，断言指标不跟随。新增指标必须附该测试才允许进 lockedsuite |
| 已落地 | `scripts/audit_directional_length_confound.py`（配对回归 `d_i = c + b·l_i`，截距 `c` = 等长效应） |

### TD-2 评价轴债（P0）

- effective depth / logit lens 自 `round-26` V185 起只出现在 **TODO 行**（`round-27`、`roadmap` 同）。
- 而 Engram 的机制主张与实测收益都在这一轴上。
- **修复**：effective depth 作为一级指标进 lockedsuite；未测指标不得在论文里被隐含为"没有效应"。

### TD-3 配置空间债（P0）

官方设计的 5 个关键量，**5 个未被扰动**：

| 官方设计 | 我们的实现 | 是否测过 |
|---|---|---|
| 表可训练（SparseAdam 5×LR） | 冻结 | ❌ |
| 表与主干**联合训练** | 冻结 | ❌ |
| gate **有选择性** | SFT 后饱和常开 0.77–0.98（round-146） | ❌（只诊断，未修） |
| 读出零初始化**但只一层 conv** | 零初始化 **3 层 MLP** | ❌ |
| **双层**注入（layer 2+15 / 1+14） | 单层 layer 2 | ❌ |

**TD-3a（接口债）**：`zero_init_out: True` 在 `src/qwen35_ple/reader_registry.py` 是**字面量**，
不是 `getattr(args, ...)`；`session-log:1253` 把 zero-init 写进 TODO 也从未执行。
→ **不仅未测，而且不可测**，除非改代码。同类：注入层数、out_proj 深度。

### TD-4 提案执行债（P1 —— 本项目的真实风险）

同一份决定性对照清单被写下**三次，执行零次**：

| 出处 | 内容 |
|---|---|
| `round-20` §3 | dual-layer / multi-layer reader 未系统测试 |
| `round-146` §4 | ①gate selectivity ②dual-layer injection ③head/order ablation ④hot-row adaptation 上界 ⑤配比 |
| `session-log:3030` | P0：dual-layer injection（layer 2 + middle）、per-dim q/k gate、special-token mask、head/order ablation |

**修复**：建立**未执行对照登记册**（`docs/unexecuted-controls.md`），版本化、带成本估计与优先级、
**与"已否决"分栏**。纪律：**低成本的决定性对照未跑完前，不允许新增科学论断。**

### TD-5 文献读入债（P1）

| 项 | 实际 | 我们记录的 |
|---|---|---|
| Memory Grafting | 核心是**换 memory value 的内容**（grafting model 隐状态） | "读取接口，不改变 PLE 表"（**记反**） |
| TokenMem | 专用通道 + 两阶段课程，治 gate 无选择性 | "不照搬 cross-attention channel；我们仍是 residual PLE"（**在诊断出病之前否决了药**） |

**修复**：文献笔记必须**可核验**（原文小节 + 原句）；每个"已否决"必须附
**能推翻该否决的实验**。否则否决不可复审。

### TD-6 停止规则误触发债（P1）

`round-153` 的停止规则（"若任何比例下都不优于同预算纯参数 → 重定位"）
由 `round-157/158` 满足 —— 但 `README:505` 自己写明**"对于「冻结嫁接」这一配置"**。
**子空间的停止被当成了方向级的关闭。**

**修复**：停止规则必须声明适用子空间；触发时**显式列出仍未测的子空间**，
不得静默关闭。

### TD-7 正面结果埋没债（P1）

| 正面结果 | 数值 | 处置 |
|---|---|---|
| oracle headroom（round-146） | raw +0.06 / chat +0.06（原文口径） | 未被后续继承 |
| `code>wiki`（round-166，等长校正） | 0.8B +0.0399 / 2B +0.2404 / 4B +0.0239，三骨干全存活 | 被当噪声 |
| 计数参照系（round-158） | 32 MB → NLL 5.3368 / top-1 25.25% | 已归档但未进主叙事 |

**修复**：建立"**活结论**清单"（`docs/live-claims.md`），正面结果与负结果**同等维护**、
同等标注配置子空间。

### TD-8 范围声明债（P2）

摘要/标题仍读作"PLE 无效"，而 README 已有范围限定。
**修复**：每个论断标注**配置子空间**四元组 ——
{表冻结/可训练} × {主干冻结/共训} × {单层/双层} × {饱和/非饱和}。

## 4. 开发计划（四阶段，每段自带停止规则）

排序原则：**先还债 → 再跑"从未测过且便宜"的轴 → 再扰动设计空间 → 最后才共训练**。
与 round-153 的 Q1–Q3 相比，主要变化是 **Stage 0 与 Stage 1 是新增的**，
且 Stage 3（共训练）**由 Stage 1 的结果授权**，不再是"下一件大事"。

### Stage 0 —— 还债（无 GPU，天级）

| # | 事项 | 出口判据 |
|---|---|---|
| 0.1 | 滋扰变量扰动测试框架（TD-1） | 每个 lockedsuite 指标都有"只动滋扰变量"的测试并通过 |
| 0.2 | 未执行对照登记册（TD-4） | `round-20`/`round-146`/`session-log` 三份 TODO 合并，分栏"已否决/未执行/已完成"，每项带成本 |
| 0.3 | 配置空间可扰动（TD-3a） | `zero_init_out`、注入层、out_proj 深度成为 config 字段（**纯新增，零行为变化**） |
| 0.4 | 文献笔记可核验（TD-5） | Memory Grafting / TokenMem 两条更正落地；每个否决附可推翻实验 |
| 0.5 | 活结论清单 + 范围四元组（TD-7/8） | `docs/live-claims.md`；论文摘要按四元组重述 |

**停止规则**：0.1 未完成前不启动任何 GPU 实验 —— 否则新数字同样不可信。

### Stage 1 —— 两条从未测过的轴（现有 checkpoint，GPU 天级）★最高性价比

| 子项 | 手段 | 为何决定性 |
|---|---|---|
| 1a **有效深度**（TD-2） | 在 0.8B/2B/4B 现有 checkpoint 上，PLE 开/关对比：logit-lens KL、top-5 overlap、残差余弦相变点、跳层影响、残差擦除 | 直接检验 Engram 的机制主张；**从未测** |
| 1b **read-out 初始化与秩**（TD-3） | 同架构，`zero_init_out ∈ {True, False}` × out_proj 深度 ∈ {1,3}，并**训练全程记录** `value_proj` / `branch_sum` / `c_t` 的 PR | rank-collapse 理论预测零初始化+深度**必塌**；若换初始化不塌 → "不可修"收窄 |

**读法（预注册，三选一）**：

| 结果 | 结论 |
|---|---|
| 1a 正（ED 上升）、知识持平 | **在冻结嫁接下复现 Engram 悖论** → 目标重定位为"深度释放+表面先验" |

| 1a 零、1b 提高 PR 后 ED 上升 | 塌缩是约束 → Stage 2/3 的动机拿到 |

**成本**：前向为主；(1b) 需两次短训练（已有 harness）。
**停止规则**：若三条全零，则冻结嫁接方向关闭，直接进 Stage 4 的边界条件交付。

## 5. 借鉴矩阵（按"我们缺的机制"组织）

|---|---|---|---|
| **有效深度测量** | Csordás et al. 2505.13898 + 2512.14064 | 复用其四件仪器（logit-lens KL / 残差余弦相变 / 跳层 / 残差擦除），做 PLE 开/关对比 | 不新造指标；用他们的口径以便跨论文比较 |

| **memory value 的内容** | Memory Grafting 2605.20948 | 存**grafting model 隐状态**作为 value，而非从零学的 embedding；exact longest-match + hash fallback | 不改我们的行格式；新表仍走 EngramDB |
| **专用注入通道 + 两阶段课程** | TokenMem 2607.22625 | 先补**课程**（便宜）；cross-attention 通道作为一个 config 变体，不动现有 residual 路径 | 不替换现有 residual PLE 路径；A/B 并存 |

| **负结果方法学** | kNN-LM Does Not Improve Open-Ended Generation（EMNLP 2023） | 聚合指标改善 ≠ 下游改善；"少数 token 大幅改善被多数 token 轻微恶化冲掉"这一读法 | 不把 perplexity/NLL 改善当作产品结论 |

### 5.2 兄弟仓库（按 `AGENTS.md` 的无环依赖）

| 仓库 | 借什么 | 边界（不冲突） |
|---|---|---|
| **EngramDB** | 表写入/打包、行级 patch 与版本化、Store-P 预取、bundle/serving | 存储永远 EngramDB；**不自创行格式、不写第二个存储引擎** |
| **engram-peft** | hash / gate / ShortConv 的**权威语义** + golden 对拍；官方 config 值 | pin 版本；**不写第二套 hash/gate 实现**；只新增字段 |
| **LLM-CompileForge** | 推理编译器与 Rust runtime（**我们不是它的上游**） | 依赖方向 `CompileForge → EngramDB`；我们不依赖它，也不被它依赖 |

**契约纪律**（`docs/integration-contract.md` v1 冻结）：
任何跨仓接口变化 **先改契约 → 再改实现**；**只允许新增**；
ABI 演进用 `_v2` 新符号，旧符号永不改变行为。
Stage 0.3 的"配置空间可扰动"必须走这条路（新增 config 字段，不改默认行为）。

### 5.3 冲突规避五条（沿用并强化）

1. **每层唯一真源**，跨层用 adapter；2. **跨仓 golden 对拍 + 版本 pin**；
3. **共享评测协议**，claim 不用仓库私有指标；
4. **一个统一 trainer** 覆盖 frozen / LoRA / 全参 / hot-row / 共训；
5. **存储永远 EngramDB，serving 永远是 bundle**。

## 6. 与目标的距离（诚实评估）

**已经拿到**

- 一个**可证明**的界（`round-157` §1.1，从源码逐行核实）：token n-gram 哈希寻址的通道
  **不可能**承载上下文条件化知识。这是本项目最硬的产出，且与 reader 无关。
- 一套**可复用的尺子**：计数参照系（`round-158`）、长尾分解（`round-159`）、
  塌缩溯源级联（`round-165`）、长度混淆回归（`round-166`）。
- 两个**正面信号**：`code>wiki` 三骨干存活；oracle headroom 存在。
- 端侧存储可行性（NVMe）与不崩塌的轻量适应（LoRA）。

**还没拿到**

- 任何"外部记忆优于同预算参数"的正向证据（`round-153` 起就是最大缺口，**仍未做**）。
- effective depth 的任何读数。
- 官方设计空间内任一项的扰动结果。

**因此当前最有价值的产出**，按证据强度排序：

1. **可证明的界 + 它的作用域**（已有，需把作用域写准）；
2. **机制轴判定**（Stage 1，(a) 为正则为正贡献，(a) 为负则把负结果定位到 Engram 自己的机制上）；
3. **iso-budget 相图**（Stage 4）。

> 一句话：**v1 说"别证明它有用，测它何时有用"；v3 再加一句 ——
> 先测它按自己的机制主张该在哪一轴有用，否则我们只是在最强的那一轴上继续得到零。**
