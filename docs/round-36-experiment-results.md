## 1. 实验设置

- 数据：`data/ple-books-160k`，1024 token 采样；
- 注入层：layer 8；
- 目标：真实 LM 梯度残差 \(R_t=-\partial L/\partial h_t\)；
- 方法：岭回归，\(\lambda=1.0\)；
- 指标：\(\Delta R^2(Y;E\mid H)\)。

## 3. 与预注册判读对照

### 3.1 PCA 压缩

预注册中的三种情形：

- A：低秩信号，压缩后保持；
- B：信号分散在高维，压缩后下降；
- C：所有 r 都接近 0。

实际结果属于 **B**：

> 有用信号没有被前 256 个主成分捕获；r=256 只有 +0.002，远低于全维度 +0.0058。

说明：

- **不能直接使用无监督 PCA 作为记忆压缩器**；
- 需要使用有监督的 PLS / 信息瓶颈方向，或保留更多维度；
- 当前信号可能是“广泛但微弱地分布在高维”，而不是集中在少数语义方向。

### 3.2 高/低残差子集

预注册中的情形：

- A：高残差子集更大；→ 记忆帮助难 token；
- B：高低相近；→ 全局分布偏移；
- C：低残差子集为负；→ 简单 token 受伤。

实际结果是：

> **高梯度 token 上 ΔR² 为负，低梯度 token 上 ΔR² 为正。**

这不是预注册中直接列出的一种，但最接近“B/C 的混合反转”：

- 记忆对低梯度/容易 token 有正增量；
- 记忆对高梯度/难 token 反而可能有害；
- 这说明 **当前 PLE 的线性信号主要来自高频局部 n-gram 共现，而不是长尾知识**。

---

## 4. 理论上的启示

1. **理论 A/B 仍成立**：E 有正增量，E⊥ 保留大部分，但增量很小；
2. **“记忆应该帮助难 token”是额外猜想，被本次实验否定**；
3. **当前 PLE 更擅长局部模式，而不是稀有语义事实**；
4. 这解释了为什么：
   - real 在 Trivia/NQ 上优势很小；
   - control 也能提高 logprob（因为局部 n-gram 共现并不需要真实语义顺序）；
   - BoolQ 容易退化（简单 passage 判断被局部模式干扰）。

---

## 5. 下一步

1. **改用 PLS / 监督方向压缩**，而不是无监督 PCA；
2. **在高残差 token 上测真实 reader 是否反而有害**；
3. **设计更严的“记忆任务”**：不是所有 next-token，而是稀有/长尾 token 子集；
4. **若 PLE 信息主要在低梯度 token，可能当前记忆表不适合做知识增强，只适合局部语言建模增强**；
5. 之后才决定是否进入 5M–20M / RL。
