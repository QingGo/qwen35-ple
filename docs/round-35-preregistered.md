> 日期：2026-09-03
> 状态：实验前预注册
> 目的：先写清“不同结果说明什么”，再跑实验，避免事后解释偏差。

## 1. 实验

目标：进一步验证理论预测：

1. 记忆信号是否集中在低维子空间？
2. 正交化 E⊥ 是否真的不损失信息？
3. 记忆是否主要帮助“难 token / 高残差 token”？

使用指标：

\[
\Delta R^2(Y;E\mid H)
\]

其中 \(Y=R_t=-\partial L/\partial h_t\) 是 layer 8 的真实 LM 梯度残差。

---

## 2. PCA 压缩实验结果判读

### 情形 A：低秩信号
- 现象：r 从 256 降到 32 时，\(\Delta R^2\) 基本保持，甚至上升。
- 说明：PLE 的有用信息集中在一个低维语义子空间；应使用低秩记忆瓶颈，降低噪声和计算量。
- 结论：做 \(P_{\text{mem}}\) 低维信息瓶颈是正确方向。

### 情形 B：信号分散在高维
- 现象：r 降低时 \(\Delta R^2\) 持续下降，r=16/32 几乎为零。
- 说明：有用信息分散在大量维度中，不能简单 PCA。
- 结论：可能需要非线性压缩、更多数据或更复杂的记忆读取。

### 情形 C：所有 r 都接近零
- 现象：即使 r=256，\(\Delta R^2\) 仍接近 0。
- 说明：问题不是压缩，而是 PLE 表对当前任务本身增量信息不足。
- 结论：应停止放大，先换任务或换记忆表。

---

## 3. 高/低残差子集实验判读

### 情形 A：高残差子集显著更大
- 现象：高梯度 token 的 \(\Delta R^2\) 远大于低梯度 token。
- 说明：记忆确实主要帮助“难 token / 基座不确定的 token”。
- 结论：应做 conditional gating，只在难 token 上注入。

### 情形 B：高低子集相近
- 现象：高、低子集 \(\Delta R^2\) 差不多。
- 说明：记忆当前不是“按难度选择性使用”，更像全局分布偏移。
- 结论：需要显式 gate 选择性，否则会均匀扰动。

### 情形 C：低残差子集为负
- 现象：低梯度 token 上 \(\Delta R^2<0\)。
- 说明：注入对简单 token 有负面作用。
- 结论：强烈支持 gate/稀疏化，并解释 BoolQ 退化。

## 4. 正交化 E⊥ 判读

- 若 \(\Delta R^2(E_\perp)\approx \Delta R^2(E)\)：
  理论预测成立，Value 去相关是安全且必要的。
- 若 \(\Delta R^2(E_\perp)\ll \Delta R^2(E)\)：
  说明部分记忆信号其实与 H 有交互，不能简单线性正交化；
  需要更复杂的条件化去相关，或改用条件门控。
- 若 \(\Delta R^2(E_\perp)>\Delta R^2(E)\)：
  说明原始 E 中包含大量 H 冗余噪声，去相关本身就有益。
