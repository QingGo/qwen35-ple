# Round 167 Stage 1a 结果：PLE 嫁接**没有**释放有效深度

> 日期：2026-09-13
> 预注册：`docs/round-167-stage1-effective-depth-preregistration.md`（数字产生前冻结）
> 判定脚本：`scripts/round167_stage1a_verdict.py`（规则逐字引用预注册 §4，12 项测试钉死）
> 产物：`outputs/round167/effective-depth-{0.8B,2B,4B}.json`、`outputs/round167/stage1a-verdict.json`

## 0. 一句话

**三个骨干没有一个出现 `DEPTH_FREED`；而凡是深度位移出现的地方，
`real` 与 `shuf` 位移完全相同 —— 效应来自"注入了一个 PLE 形状的向量"，
不来自向量里的内容。**

这是预注册 §5 表里的**第二种结局**，也正是我在 §6 反方预测里写下的预期。
它把论文的负结果**定位得更准**：从"在 Engram 承认收益最小的轴上为零"
变成"**在 Engram 自己归功的机制上也是零**"。

## 1. 判定结果（按预注册规则，未做任何事后调整）

| 骨干 | 层数 | TV(off,real) | kl 增益 | top5 增益 | cos 增益 | **判定** |
|---|---|---|---|---|---|---|
| Qwen3.5-0.8B | 24 | 1.7245 | 0 / 0 | **−4 / −4** | 0 / 0 | `MIXED` |
| Qwen3.5-2B | 24 | 1.0510 | 0 / 0 | 1 / 1 | 0 / 0 | **`DEPTH_NULL`** |
| Qwen3.5-4B | 32 | 0.2048 | 0 / 0 | 0 / 0 | **16 / 16** | `PERTURBATION_ONLY` |

（增益 = `ED(off) − ED(x)`，正 = 注入把转变提前 = 释放深度。斜杠两侧分别是 `real` 与 `shuf`。）

## 2. 逐层有效深度（层号）

| 骨干 | 条件 | logit-lens KL | top-5 overlap | 残差余弦 |
|---|---|---|---|---|
| 0.8B | off / real / shuf | 1 / 1 / 1 | **15 / 19 / 19** | 1 / 1 / 1 |
| 2B | off / real / shuf | 1 / 1 / 1 | **23 / 22 / 22** | 1 / 1 / 1 |
| 4B | off / real / shuf | 1 / 1 / 1 | 31 / 31 / 31 | **19 / 3 / 3** |

三条读数：

1. **logit-lens KL 在每个骨干上都完全不动**（三个条件都在第 1 层越过半高阈值）。
   预测分布稳定得很早，注入不改变这一点。
2. **top-5 overlap 只在 0.8B 上移动，而且方向是"更晚"**（15 → 19）。
   `real` 与 `shuf` 逐层相同。按预注册的增益定义这是 −4，即**注入让预测分布稳定得更晚**。
3. **4B 的残差余弦发生了全实验最大的位移**：off 的第 19 层 → real 与 shuf 的第 3 层。
   而 **`shuf` 与 `real` 完全相同**。

## 3. 为什么这仍然是一个干净的结论

三条独立的读数都指向同一件事：

```text
凡是注入改变了深度读数的地方，shuf 与 real 给出同一个数
  => 效应由"注入了 PLE 形状的向量"驱动
  => 与向量承载的内容无关
```

这与 `round-162` 的 `PERTURBATION_ARTIFACT`、`round-165A` 的
`c_t` PR 1.020 / `cos(real, shuf)` 0.9966 完全一致 ——
**读出层输出的近常量，在深度几何上也表现为一个与内容无关的推挤。**

4B 的反差值得单独记一笔：它的 TV 只有 **0.205**（0.8B 是 1.72），
即注入对**最终分布**的扰动最小，却对**残差几何**的读数影响最大（19 → 3）。
说明"深度几何"与"输出分布"是两个可分离的量，深度读数变早**不等于**输出变好。

## 4. 预注册规则的一个缺口（诚实记录，不追溯修改）

预注册 §4 只设想了**非负**增益：`DEPTH_FREED` 与 `PERTURBATION_ONLY` 都要求
`gain_real ≥ 2`，`DEPTH_NULL` 要求 `|gain_real| < 2`。**没有覆盖 `gain_real ≤ −2`
（注入让深度转变更晚）**。0.8B 的 −4 正好落进这个缺口，于是规则返回 `MIXED`。

处理方式：

* **0.8B 的判定保持 `MIXED` 不变** —— 规则是预注册的，事后改它就是作弊。
* 缺口本身记为一条**规则债**：`DEPTH_WORSENED` 应作为第六种结局存在。
  下次使用该规则前必须先补，且不得用它重判本轮结果。
* `MIXED` 在本轮的**描述性**读法（不是判定）是：KL 与余弦不动、
  overlap 后移 4 层且 `real == shuf`，即**没有深度释放，只有内容无关的扰动**。

## 5. 这是哪一种结局，对计划的含义

对照预注册 §5：

| 结局 | 是否命中 | 含义 |
|---|---|---|
| `DEPTH_FREED` | ❌ | 冻结嫁接没有在 Engram 归功的机制上释放深度 |
| `DEPTH_NULL` / `PERTURBATION_ONLY` | ✅ | **冻结加性嫁接在它被归功的机制上也是零/扰动 → 支持"必须共训"** |

按预注册 §5 写定的后果：**Stage 3（联合训练小表）获得强动机**；
而论文的负结果定位变准 —— 我们的零不是"测错了轴"，而是
**Engram 的机制主张在"冻结 + 加性 + 单层"这一配置下也不成立**。

**但仍要留住的限定**（预注册 §6 已写定）：官方是**共训**的，主干会把注入纳入计算。
本实验证伪的是**冻结加性嫁接**，不是 Engram 本身。若把这条读成"Engram 的机制主张是错的"，
就重复了 `round-157` §7.2 已经更正过一次的过度声称。

## 6. 与 Stage 1b 的关系

Stage 1a 用的是无 SFT 的读出（三骨干一致）。生产配方的读出是**零初始化 + 双层 MLP**，
即三条理论（官方 `conv_zero_init`、arXiv 2510.06954 的 condensation→rank collapse、
ICML 2026 的深度隐式低秩偏置）共同预测会塌缩的配置。

若 Stage 1b 显示"换初始化 / 减深度后 PR 上去、且深度读数随内容变化"，
则本轮的 `DEPTH_NULL` 应重新表述为**"读出缺陷掩盖了深度效应"**，而不是"深度效应不存在"。
两轮的分工必须一起读，不能单独引用 Stage 1a。

## 7. 工程记录：吞吐（值得留档的 6× 提速）

第一版按 batch=1 跑，GPU 利用率 **9%**（单条 prompt 约 30 token，填不满 4090），
0.8B / 200 条需约 6 分钟。两处改动：

| 改动 | 效果 |
|---|---|
| **按 token 预算批处理**（BoolQ 约 300 token vs NQ 约 20，固定条目数不是正确的批单位） | 填满 GPU |
| **绕过 `lm_head`**：直接调 `model.model` 而非因果 LM 包装器 | 包装器会对**每个位置**做 248,320 维投影（batch 32 × 300 token ≈ **10 GiB**），而本脚本自己算 logits，纯属浪费 |

结果：**0.8B 从约 6 分钟降到 <1 分钟，GPU 利用率 9% → 100%**。
数值等价性**先验证后采信**：batch=1 vs batch=32 上，top-5 overlap **逐位相同**，
KL 最大差 3.7e−5，余弦最大差 4.4e−7，有效深度判定完全一致。
4B 需按骨干单独设 token 预算（8192 会 OOM，2048 通过）。
