# Round 61：RAG 评测污染审计

> 日期：2026-09-04
> 状态：已完成第一版泄漏审计
> 目的：确保 RAG baseline 的收益不是由评测答案直接命中语料造成的假象。

---

## 1. 审计方法

- 输入：rare-kb 270 题（仅检查答案长度 ≥2 个词的条目）；
- 检索语料：`data/sources/wikitext.jsonl` 前 20,000 docs；
- 判据：归一化后的答案字符串是否作为子串出现在语料中。
- 说明：这是保守审计；即使答案未整句出现，检索仍可能提供部分证据。

## 2. 结果

| 项 | 值 |
|---|---|
| QA 总数 | 270 |
| 可检查答案数 | 165 |
| 在语料中出现的答案数 | 11 |
| 表面污染率 | **6.7%** |

## 3. 解读

- 6.7% 的答案在 wikitext 中能找到完整字符串；
- 这不是“大部分答案都泄漏”，但不能忽略；
- RAG 的收益仍然主要来自**语义相关的上下文**，而不是简单复制答案；
- 后续更严格的评测应：
  1. 增加排除集；
  2. 检查问题-答案对是否都在语料中；
  3. 对 retrieval hit 的文档做人工抽样。
