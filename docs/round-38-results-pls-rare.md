## 2. 与预注册对照

### 2.1 PLS：属于情形 A/B 之间，偏向“监督低秩有效”

预注册：

- A：低 r 保持/提升；
- B：需要高 r；
- C：完全不显著。

实际：

- r=16 已恢复约一半；
- r=64 超过全维度基线；
- r=128/256 进一步上升。

因此：

> PLS 监督方向显著优于无监督 PCA。
> 有用记忆信号确实存在于一个约 64–128 维的监督低秩子空间中，并且去噪后甚至比全维度更好。

结论：**下一步应使用 PLS/有监督低秩记忆瓶颈，而不是无监督 PCA。**

### 2.2 稀有 vs 常见：属于情形 A

预注册：

- A：稀有 token 正增量更高；
- B：常见 token 正、稀有 token 零/负；
- C：两者都接近零。

实际：

> 稀有 token ΔR²=+0.0152，是常见 token +0.0079 的约 2 倍。

因此：

> PLE 确实对稀有 token 提供更多增量信息，符合“记忆服务于长尾知识”的假设。

---

## 3. 综合解释

结合上一轮高/低梯度结果：

1. **高梯度 token 上 ΔR² 为负**：可能是高梯度 token 本身噪声大，线性模型无法利用；
2. **稀有 token 上 ΔR² 显著更高**：说明 PLE 确实含有长尾信息；
3. **PLS 压缩后 ΔR² 超过全维度**：说明大部分信号可以被低秩监督方向捕获，去掉噪声后更干净。

因此当前理论预测与实验的修正版是：

- 记忆有用；
- 它更偏向稀有 token；
- 它可以用监督低秩方向提取；
- 但它对“最难/高梯度” token 未必有帮助，可能因为那些 token 超出了当前线性提取能力或属于真正不可预测噪声。

---

## 4. 下一步

1. **实现 PLS 低秩记忆瓶颈**：用有监督方向 \(W\) 将 E 压到 64–128 维；
2. **用稀有 token 任务重测 real vs control**，而不是全量 QA；
3. **测试当前 reader 在稀有 token 上的实际表现**；
4. **Oracle MLP**：看非线性是否能进一步利用高梯度 token 上被线性模型浪费的信号；
5. 如果稀有 token 子集上 real−control 明显提升，才考虑进入更大规模训练。
