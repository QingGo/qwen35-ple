# Round 168 撤回：规模"衰减"是生成上限的产物，不是被证实的预言

> 日期：2026-09-13
> 触发：用户问"2B 那个异常点怎么办"，去查原始产物
> 结论：**TD-12 必须撤回。** `0.4159 → 0.5832 → 0.0098` **不是**单调衰减，
> 而且 4B 那个"0"是**不可识别**，不是零。把不可识别读成零，
> **正是我们自己的停止清单上写着不许做的那件事。**

---

## 0. 我说过什么，错在哪

我在 LIFTS 分析与论文故事里反复用过这句话：

> `round-166`：散文效应 0.8B **+0.4159** → 2B **+0.5832** → 4B **+0.0098（p=0.44）**，
> 正是压缩论证所预测的"能力增益随规模缩小"。**这是被证实的可证伪预言。**

**这句话有三处错。**

---

## 1. 错处一：中间点最大，不是单调衰减

`docs/round-166-unsaturated-multibackbone-results.md` §3 的原始表：

| 预测 | regime | 原始差 | 长度校正后 $c$ | 斜率 | 判读 |
|---|---|---|---|---|---|
| `wiki>code` (prose) | 0.8B | +0.6933 | **+0.4159 ± 0.0458** (p=5.4e−20) | +0.0790 | 存活（缩水 40%）|
| | 2B | −0.6800 | **+0.5832 ± 0.0809** (p=2.8e−13) | +0.0633 | 符号翻转 → 通过 |
| | 4B | −0.8467 | **+0.0098 ± 0.0668 (p=0.44)** | +0.0823 | **归零 → 不可识别** |

**2B (0.583) > 0.8B (0.416)。** 所以"随规模减小"这个形状在这三个点上**根本不存在**。

---

## 2. 错处二：4B 的"零"是生成上限造成的**不可识别**

`--qa-max-new-tokens 32` 在 code/stem 上就是硬约束（原文：**94–99.8% 触顶**）。
逐臂生成长度（`analysis.md`，mean / **median**）：

| regime | wiki | code | stem | ple-off |
|---|---|---|---|---|
| 2B | 11.77 / **0** | 31.72 / **32** | 30.32 / 32 | 31.93 / 32 |
| 4B | 21.02 / **24** | 31.43 / **32** | 31.96 / 32 | 31.23 / 32 |

**`wiki>code` 比的是 wiki 臂与 code 臂**，而 code 臂在**两个规模上都钉在 32**。
配对不一致计数把这一点暴露得最清楚（原文方向性预测表）：

```text
2B  wiki>code:prose   n_a_only =  15   n_b_only = 251
4B  wiki>code:prose   n_a_only =   3   n_b_only = 209
```

**209 / 212 的不一致全部来自一侧。** 回归 $d_i = c + b\,l_i$ 的自变量 $l_i$
在 code 侧退化（几乎全是 0），所以截距 $c$ 是**外推出来的**，p=0.44 =
**不可识别**，不是"效应为零"。

再加上一个结构性问题：**`prose` 是"6 个标记里出现了几个"的计数**（原文 §3 自己指出的），
**对生成长度单调**。所以这个指标本身在触顶 regime 里就无法做等长校正。

---

## 3. 错处三：这个指标**不是能力指标**

`prose` / `code` / `math` 是**格式-词法指纹**（"记忆的语料表面统计有没有到达输出"），
**不是"模型变得更好"**。原文自己写着：

> 描述子层面的内容依赖……`prose` 方向性预测在三个 regime 里都被长度混淆。

也就是说：**这三个数字从来没有、也不可能支撑"能力增益随规模缩小"**。
它们能支撑的只是论文已有的那句更弱的、也更准确的话——
**"剩下的分布携带该语料的表面统计，也就是界所允许的 trigram 先验"**。

---

## 4. 后果（必须落地的三条）

1. **撤回 TD-12。** 它不是"预测被证实"，它是**一个未识别点的误读**。
   计划 v3 里 TD-12 那一行、以及我口头引用过的"规模趋势"，全部作废。
2. **论文里禁止写"规模衰减"。** 若要谈规模，必须：**4B 重跑，抬高 `--qa-max-new-tokens`**
   （或换一个**长度不变**的指标），让等长效应**可识别**；否则只能写"在 0.8B 与 2B 上，
   表面统计的可达性存在，且 2B 更强；4B 未识别"。
3. **端侧论证不得依赖这条趋势。** 我在 §6 用"规模趋势支持端侧论"——
   **那条依据撤销**。端侧主张只能靠**确定性卸载**与**iso-服务成本**两条，不能靠这个。

---

## 5. 这次撤回本身的价值

这是**同一类错误的第三次出现**，而这次是**我们自己犯的**：

| # | 把"测不到"读成"不存在" | 出处 |
|---|---|---|
| 1 | 长度/scaffold 混淆把方向性数字放大 40% | `round-162`（`round-166` 才发现）|
| 2 | 线性解码器失明被读成"没有互补信息" | `round-168` CMI 探针自证伪 |
| 3 | **生成上限造成的不可识别被读成"效应归零"** | **本文** |

**它证明了两件事**：① 停止清单上"把测不到写成不存在"这条**不是形式主义**，
我们自己就在犯；② **1.5c/1.5e/1.5f 里那套"必须带 null / 必须双向验证"的规矩，
对内部文档同样适用**。

**给论文的直接好处**：§6 那节从"预言被证实"（**不成立**）改成
**"一个看似支持我们的趋势，在检查后塌掉了——而这次是我们自己抓的"**。
后者对一篇讲测量的论文来说，是更强的证据，不是更弱的。
