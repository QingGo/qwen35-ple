## 0. 为什么要这条曲线

阶③回归 R = 0.51–0.74:在同一批位置、同一候选集下,行只复现了显式计数表的
一半到四分之三。有两个解释都活着,而且**预测不同的曲线**:

| 解释 | 预测 |
|---|---|
| **测量受限** — K 越小,显式计数基线越弱(样本更少、argmax 空间更小) | R 应随 K 变小而**趋近 1** |
| **内容受限** — 行里装的确实是一个退化的先验 | R 应在一个**低于 1 的平台**上不动 |

这条曲线就是判别式。R 的定义与阶梯③完全一致:`R = probe_raw_rows top-1 / count_trigram top-1`。

### 1.1 ⚠️ 必须披露:冻结的 `ROWS_CARRY_THE_TRIGRAM` **不是 K-鲁棒的**

**wiki 在 K=20000 时 R = 0.4858,低于冻结规则 §3 的 0.50 地板** ——
若把这个 K 喂给冻结规则,它会读成 `ROWS_DEGRADED`。

冻结判定**不变**,因为预注册 §2 把位置集与候选集冻结为 **K=5000(主)+ K=1000(敏感)**,
两者都是 CARRY;§4.1 的敏感性条款只在**这两个** K 之间裁决。
但结论必须随之限定:

> **"行承载三元组先验"这个判定是依赖候选集的。**
> 在更宽的候选集上,wiki 的同一个量会跨过地板。

这一条不影响 `ROWS_CARRY_THE_TRIGRAM` 的有效性(它按冻结规则成立),
但它**限制了这句话能外推到多宽的候选集** —— 后续任何引用该判定的人都需要知道。

## 2. 三条读数

**① 缺口主要是「内容受限」,不是「测量受限」。**

**stem 是决定性的**:K 跨 **100 倍**(200 → 20000),R 只从 0.5319 动到 0.5026 ——
几乎是平的。wiki 与 code 确实随 K 变小而上升,但幅度温和(0.509 → 0.586;0.693 → 0.797),
**外推到 K→0 也够不到 1**。

⇒ 行的内容**确实是一个退化的三元组先验**。增大候选集不是解释缺口的主要变量,
所以"把 K 调小就能让行看起来更好"这条退路不成立。

**② 一个事先没预料到的分裂:stem 的读出已饱和,wiki/code 没有。**

`MLP/linear` 比:

```text
stem : 0.991 – 1.018   ← 非线性读出一点也帮不上
wiki : 1.075 – 1.106
code : 1.094 – 1.156   ← 非线性读出多拿 9–16%
```

这是 TD-9 那条警告的**量化版**:线性 R 是**下界**,而且下界的松紧**因域而异**。
对 wiki/code,缺口里有一部分是**解码器容量**而不是行内容;对 stem,不是 ——
stem 的行已经被线性读出榨干了,多出来的全是内容损失。

**③ 所以"损失定位在阶④"这句话要加限定。**

原判据说"损失定位在读出(阶④)"。曲线把它细化成:

| 域 | 内容损失(阶③) | 读出损失(阶④) |
|---|---|---|
| stem | **大**(R≈0.50 且 MLP 无增益) | — |
| wiki | 中(R≈0.51–0.59) | 有(MLP +8–11%) |
| code | 小(R≈0.69–0.80) | 有(MLP +9–16%) |

即 **code 的行其实相当好**,它的损失更多在读出;stem 相反。

## 3. 承限

1. **K 不是连续变量**,5 个点里每个都换了候选集,所以 probe 与 count 的**难度一起变**;
   这条曲线读的是 R 的**趋势**,不是某一点的绝对值。
2. 仍受 TD-9 限制:**两个探针都是下界**,`ROWS_DEAD` 那一档依旧要求两者都不超过对照。
3. 位置级差异在相邻位置间高度相关(同一三元组、同一流),所以这里的 SE 不可直接当独立样本用;
   本曲线不做显著性判定,只报趋势。
4. 全部为 0.8B + 冻结行 + 固定 reader 配置,不外推到其它规模。

## 4. 它对下一步的影响

* 阶③不是空的(冻结判定),而且**内容损失是真实的**(本曲线)⇒
  "把读出修好就能拿到全部价值"这个希望被削弱,但**没有死**——因为 code 的 MLP 增益
  证明仍有可回收结构。
* 对 B1 的意义:B1 训练的是**行**。本曲线说明行的内容确实有损,
  所以"行可以被重塑"这件事**值得测**,而且**应当分域看**:stem 最需要内容修复,
  code 最需要在读出上找回来。
